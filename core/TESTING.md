# Core 隔离验证

## 可能失败的情况

- UTF-16 代理对被拆成两个 `char` 检查，导致补充平面汉字漏检或误判。
- CJK 扩展区间上界写错，或把未分配空位当作 Han 字符。
- 空值或空序列触发异常，或者检测过程创建了不必要的字符串副本。
- Ruby 原文范围越界、长度为零，或起止位置切开代理对。
- `RubySegment` 可变状态泄漏。
- Han 候选字符检测被误当成日语识别，纯中文字符因此被判为日语。
- U+3007（IDEOGRAPHIC NUMBER ZERO）等范围之外的表意数字被误纳入 Han 检测。

核心模块使用 JUnit 4 验证上述边界。该测试只验证纯 Java 数据与 Unicode 逻辑，不模拟 Android、LSPosed 或任何外部服务。
